Compress a PDF and Compare File Size

Optimize a PDF with light, balanced or smaller-output settings, then compare actual byte sizes. Download appears only if a smaller valid PDF is produced.

Processed temporarily on the server; uploaded files are deleted after the job.

How to use this tool

  1. Choose a PDF within the file and page limits.
  2. Select light, balanced or small output based on the image detail you need.
  3. Run compression, compare original and result byte counts, then download and inspect the PDF.

Practical example

For an image-heavy report, try balanced first; inspect charts and small labels after downloading before sharing it.

Understanding the result

A successful result has the same page count and dimensions and fewer bytes. Image downsampling can reduce visual detail; already optimized PDFs may show no gain.

Options and workflow

Upload a PDF and choose light, balanced or small output. The result displays actual byte counts before and after processing.

Limits and privacy

Up to 15 MiB and 50 pages. The optimizer may downsample images; review image legibility after download. If no smaller valid PDF is produced, keep your original. The uploaded file is removed after processing.

Common questions

Will every PDF become smaller?

No. Some PDFs are already optimized. This tool reports no gain instead of calling a larger file compressed.

Does the preset guarantee a target size?

No. Presets change image resolution during optimization; the final size depends on the source PDF.
