Build UTM Campaign URLs

Create encoded campaign links with source, medium and campaign tags while keeping existing query parameters and fragments in the destination URL.

Processed in your browser; no file upload.

How to use this tool

  1. Enter the destination HTTP or HTTPS URL.
  2. Fill in source, medium and campaign; add term or content when useful.
  3. Generate the link, review its parameters and copy it from the list.

Practical example

For a newsletter link, use source=newsletter, medium=email and a campaign name that identifies the send.

Understanding the result

The URL contains encoded UTM parameters. Existing non-UTM parameters and the fragment remain; an existing matching UTM value is replaced.

Options and workflow

Enter an HTTP or HTTPS destination and the required source, medium and campaign. Optional term and content values help distinguish ads. Each generated URL stays in a copyable list for this tab.

Limits and privacy

Changing a UTM value replaces that parameter. Empty optional fields remove their matching parameter. Existing non-UTM query values and fragments remain. Nothing is sent to a server.

Common questions

Will an existing query string survive?

Yes. URL parsing retains its parameters and fragment; the browser may normalize their encoding when it serializes the URL.

Can I make several variants?

Yes. Each generated link appears in this tab’s list, up to 25 entries. Copy the variants you need before closing it.
