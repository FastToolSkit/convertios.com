<section><h2>What happened</h2><p>On 19 August 2026, the <a href="https://pdfa.org/no-excuses-brotli-compression-advances-pdf/">PDF Association announced</a> an industry specification for Brotli compression in PDF. It defines a <code>BrotliDecode</code> filter that PDF creators and readers can implement for compressed streams. The publication gives vendors a common technical target; it is not an automatic update to every existing PDF application.</p><p>The association describes Brotli as a lossless alternative to older stream filters such as Flate and LZW. Its <a href="https://pdfa.org/resources/">technical resources</a> provide the place to find the specification. Some named applications already support the filter, but support must be checked in the exact software version used by the people who receive a file.</p></section>
<section><h2>How the change works</h2><p>A PDF can contain compressed streams for parts of its content. A reader encounters the filter name, decodes that stream, and then interprets the underlying document data. Lossless means the encoded data can be recovered; it does not mean every PDF becomes dramatically smaller. Text-heavy or repetitive material may behave differently from photographs already compressed inside the PDF.</p><p>This also differs from reducing image quality. Re-encoding a photo at lower resolution can make a document smaller while removing detail. Brotli's stream compression is a separate choice made by PDF software. A writer that creates Brotli-compressed content and a reader that decodes it must agree on the format, so interoperability matters as much as file size.</p></section>
<section><h2>What it means for users</h2><p>If you distribute invoices, manuals or forms to an unknown audience, the smallest possible PDF is not necessarily the safest choice. Open a sample in the same desktop, mobile and browser readers your recipients use. If any reader cannot open it, ask the creating application for a broadly compatible export and retain the original for comparison.</p><p>If your real task is editing text, you can <a href="/pdf-to-word/">convert a text-based PDF to Word</a> and inspect the result. If you need selected pages as images, <a href="/pdf-to-jpg/">turn PDF pages into JPG files</a>. Neither workflow demonstrates Brotli support or substitutes for testing a Brotli PDF in the recipient's viewer.</p></section>
<section><h2>Practical checklist</h2><ul><li>Ask the PDF producer whether Brotli encoding is enabled and whether a conventional export is available.</li><li>Test a representative file in the actual reader versions used by recipients, including mobile.</li><li>Compare readability, images, searchable text and file size before distributing a large batch.</li><li>Keep a compatible fallback when the audience or its software is unknown.</li></ul></section>
<section><h2>Limitations and what has not changed</h2><p>The announcement is a specification, not a universal compatibility guarantee or a benchmark for a particular document. It does not improve blurry scans, add missing text, repair tags, or make a PDF accessible. A scanned page remains an image until a separate OCR process recognizes text; <a href="/blog/scanned-pdf-to-word/">our guide to scanned PDF conversion</a> explains that distinction. Convertios does not claim to create or decode Brotli-compressed PDFs.</p></section>

Ela define um filtro <code>BrotliDecode</code> que programas de criação e leitura de PDF podem implementar para fluxos comprimidos. <section><h2>Como a mudança funciona</h2><p>Um PDF pode guardar partes do seu conteúdo em fluxos comprimidos. O leitor encontra o nome do filtro, descomprime aquele fluxo e então interpreta os dados do documento. "Sem perdas" quer dizer que os dados originais podem ser recuperados por completo; não quer dizer que todo PDF ficará muito menor. Material com muito texto ou repetitivo pode se comportar de forma bem diferente de fotos que já estavam comprimidas dentro do PDF.</p><p>Isso também é diferente de reduzir a qualidade das imagens. Recodificar uma foto em resolução menor pode diminuir o documento, mas elimina detalhes. A compressão de fluxos com Brotli é outra escolha, feita pelo software que gera o PDF. O programa que cria o conteúdo com Brotli e o que o lê precisam concordar sobre o formato, por isso a interoperabilidade importa tanto quanto o tamanho.</p></section>
<section><h2>O que muda para quem usa</h2><p>Se você envia notas fiscais, manuais ou formulários para um público que não conhece, o menor PDF possível nem sempre é a escolha mais segura. Abra uma amostra nos mesmos leitores de computador, celular e navegador que os destinatários usam. Se algum deles não conseguir abrir, peça ao aplicativo de origem uma exportação amplamente compatível e guarde o original para comparar.</p><p>Se a sua tarefa real é editar o texto, você pode <a href="/pt-br/pdf-to-word/">converter um PDF com texto para Word</a> e revisar o resultado. Se precisa de algumas páginas como imagem, <a href="/pt-br/pdf-to-jpg/">transforme páginas do PDF em JPG</a>. Nenhum desses fluxos comprova suporte a Brotli nem substitui o teste de um PDF com Brotli no leitor do destinatário.</p></section>
<section><h2>Checklist prático</h2><ul><li>Pergunte a quem gera o PDF se a codificação Brotli está ativada e se existe uma exportação convencional.</li><li>Teste um arquivo representativo nas versões reais dos leitores usados pelos destinatários, incluindo celulares.</li><li>Compare legibilidade, imagens, texto pesquisável e tamanho antes de distribuir um lote grande.</li><li>Mantenha uma alternativa compatível quando o público ou o software dele forem desconhecidos.</li></ul></section>
<section><h2>Limites e o que não mudou</h2><p>O anúncio é uma especificação, não uma garantia de compatibilidade universal nem um teste de desempenho para um documento específico. Ele não melhora digitalizações borradas, não acrescenta texto ausente, não corrige tags e não torna um PDF acessível.
