Meeting PDF upload requirements for applications and portals

"File must be a single PDF under 2 MB." Upload rules like this cause more failed applications than missing documents. Most can be met in a few minutes once you know what each rule is really checking.

  • CategoryPDF & Documents

  2. Checks portals often apply without telling you

The rules you will meet most often

"PDF only"

The portal wants a document that looks the same for every reviewer. Export Word or Google Docs files with "Save as PDF"; turn photos of paper documents into a PDF with JPG to PDF; see making a PDF from phone photos.

"Maximum file size"

Limits of 1, 2, 5 or 10 MB are common. The usual cause of large PDFs is high-resolution scans or photos. Rescanning at a sensible resolution, or exporting with a smaller image setting, usually fixes it; our guide to reducing PDF file size explains the options. Leave a margin: if the limit is 2 MB, aim for 1.8 MB.

"Upload one file"

When several documents must go into one field, combine them in a logical order with Merge PDF, which works in your browser. Put a cover page or the most important document first.

"Only pages X to Y" or "first page only"

Use Split PDF to extract just what is requested, rather than uploading a whole 40-page file.

"Pages must be upright"

Sideways scans annoy reviewers and can fail automatic checks. Fix them with Rotate PDF before uploading.

Checks portals often apply without telling you

  • File name characters. Some systems reject names with spaces, accents or symbols. Use something like Surname_Firstname_Transcript.pdf; see file naming habits.
  • Password protection. Encrypted PDFs often cannot be processed. Remove the password in the app that created it before uploading.
  • Readable text. Some portals extract text automatically. A blurry phone photo may be accepted but unreadable to the reviewer; make sure the scan is sharp and well lit.
  • Page size. A4 or US Letter is safest. Very long "single page" scans can display badly.

A five-minute pre-upload checklist

  1. Open the final PDF and scroll through every page.
  2. Confirm the page order and that nothing is upside down or cut off.
  3. Check the file size against the limit.
  4. Check that names, dates and reference numbers are legible at 100% zoom.
  5. Rename the file clearly, and keep a copy of exactly what you submitted.

If the portal still rejects it

  • Try another browser; some upload widgets are fussy.
  • Re-export from the original instead of repeatedly converting the same PDF.
  • If a document truly cannot be reduced below the limit, contact the organisation and ask about alternatives. Many accept a link or a separate email for oversized files.

Privacy note

Merge, split, rotate and JPG to PDF on Convertios run in your browser, so the documents are not uploaded to our server for those steps. Still, only upload identity documents and certificates to portals you trust, and remove extra pages that contain data the application does not need.
