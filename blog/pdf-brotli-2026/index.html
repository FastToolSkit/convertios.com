Brotli in PDF: a new compression specification and its compatibility limits

The PDF Association specified a Brotli filter for PDF. It may reduce file size in compatible software, but recipients still need a reader that supports it.

Source date19 August 2026

Published by Convertios11 Nov 2026

Original sourcePDF Association

What happened

On 19 August 2026, the PDF Association announced an industry specification for Brotli compression in PDF. It defines a BrotliDecode filter that PDF creators and readers can implement for compressed streams. The publication gives vendors a common technical target; it is not an automatic update to every existing PDF application.

The association describes Brotli as a lossless alternative to older stream filters such as Flate and LZW. Its technical resources provide the place to find the specification. Some named applications already support the filter, but support must be checked in the exact software version used by the people who receive a file.

How the change works

A PDF can contain compressed streams for parts of its content. A reader encounters the filter name, decodes that stream, and then interprets the underlying document data. Lossless means the encoded data can be recovered; it does not mean every PDF becomes dramatically smaller. Text-heavy or repetitive material may behave differently from photographs already compressed inside the PDF.

This also differs from reducing image quality. Re-encoding a photo at lower resolution can make a document smaller while removing detail. Brotli's stream compression is a separate choice made by PDF software. A writer that creates Brotli-compressed content and a reader that decodes it must agree on the format, so interoperability matters as much as file size.

What it means for users

If you distribute invoices, manuals or forms to an unknown audience, the smallest possible PDF is not necessarily the safest choice. Open a sample in the same desktop, mobile and browser readers your recipients use. If any reader cannot open it, ask the creating application for a broadly compatible export and retain the original for comparison.

If your real task is editing text, you can convert a text-based PDF to Word and inspect the result. If you need selected pages as images, turn PDF pages into JPG files. Neither workflow demonstrates Brotli support or substitutes for testing a Brotli PDF in the recipient's viewer.

Practical checklist

  • Ask the PDF producer whether Brotli encoding is enabled and whether a conventional export is available.
  • Test a representative file in the actual reader versions used by recipients, including mobile.
  • Compare readability, images, searchable text and file size before distributing a large batch.
  • Keep a compatible fallback when the audience or its software is unknown.

Limitations and what has not changed

The announcement is a specification, not a universal compatibility guarantee or a benchmark for a particular document. It does not improve blurry scans, add missing text, repair tags, or make a PDF accessible. A scanned page remains an image until a separate OCR process recognizes text; our guide to scanned PDF conversion explains that distinction. Convertios does not claim to create or decode Brotli-compressed PDFs.
