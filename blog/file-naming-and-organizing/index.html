File naming and folder habits that save hours later

Most "lost" files are not lost; they are called "Document1", "scan0004" or "final_FINAL_v3". A few consistent naming rules make every search faster and every attachment clearer.

  • CategoryProductivity & Digital Guides

Why names matter more than folders

Search is now how most people find files, on computers, phones and cloud drives. Search works on names and contents, so a clear name helps even when the file ends up in the wrong folder. A good name also tells the recipient of an email what they are opening before they open it.

Five rules that cover most situations

1. Put dates first, in year-month-day order

Write dates as 2026-11-18. This international format (ISO 8601) sorts correctly in every file list: alphabetical order equals chronological order. Formats such as 18-11-2026 or 11-18-2026 sort by day or month first and scatter a year's files.

2. Say what it is, briefly

Include the subject and document type: 2026-11-18_lease-renewal_letter.pdf, 2026-Q3_sales-report.xlsx, passport_scan_front.jpg.

3. Use one separator style

Spaces work on most modern systems but can break links and some uploads. Hyphens or underscores are safest. Pick one style and stick to it, for example underscores between parts and hyphens within words.

4. Version with numbers, not adjectives

Use v01, v02, v03 rather than "new", "final" or "latest". If you must mark the approved version, add a status at the end: _v04_approved. Two-digit numbers keep v10 sorting after v09.

5. Avoid problem characters

Slashes, colons, question marks, asterisks, quotation marks and some symbols are not allowed in file names on some systems or cause trouble in links. Keep names reasonably short; very long paths can fail when files are copied or zipped.

A simple folder structure

Folders are still useful for grouping. A shallow structure is easier to maintain than a deep one:

  • one top-level folder per area of life or work (Home, Finance, Work, Studies),
  • a folder per year or per project inside,
  • an "Inbox" or "To sort" folder for new downloads, emptied weekly.

Habits for documents you receive and send

  • Rename downloads immediately. "scan0004.pdf" becomes 2026-11-18_electricity-bill.pdf the moment you save it.
  • Combine related files into one PDF for submissions, named for the purpose: Surname_Application_2026.pdf. See how to merge PDFs and use Merge PDF, which runs in your browser.
  • Extract only what you send. When a request needs one page, save it with its own clear name using Split PDF.
  • Keep originals separate from edited copies. Add _web, _compressed or _edited to the copy, never overwrite the original.
  • Convert to common formats before sharing. A HEIC or WebP image may not open for the recipient; the Image Converter can produce JPG or PNG in your browser.

Back up what matters

Good names do not help if the file is gone. Keep important documents in at least two places, for example a cloud service and an external drive, and check occasionally that backups actually open.

Quick template

YYYY-MM-DD_subject_type_v01.ext

Example: 2026-11-18_kitchen-quote_comparison_v02.pdf. Adapt it, but use the same pattern every time; consistency is what makes it work.
