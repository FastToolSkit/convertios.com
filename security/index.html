Security & Privacy

File Privacy

Your files remain completely private throughout the entire process. We do not access, review, or analyze your content in any way. All operations are automated, ensuring that no human interaction is involved at any stage.

No File Storage

Most tools run entirely in your browser, so the file never reaches our servers. The few tools that need server processing (PDF to Word, Video Converter and Video to MP3) keep your file in a temporary folder only for that request and delete it automatically when it finishes. The AI Image Enhancer is the exception: it uploads images to Cloudinary, as explained on its page and in our Privacy Policy.

Secure Communication

All data transfers are protected using HTTPS encryption, ensuring that your files are securely transmitted between your device and our servers. This prevents unauthorized access, interception, or data leaks during upload and download.

Personal Data Protection

No account, name or email address is needed to use any tool. Like most websites, we use Google Analytics to measure usage and Google AdSense to show ads, both of which use cookies. Our Privacy Policy explains this and how to opt out.

Secure Processing

In-browser tools never send your file anywhere. On the processing server, each request gets its own temporary folder, so files from different users are never mixed, and that folder is deleted when the request ends. The AI Image Enhancer (Cloudinary) and the Link Shortener (TinyURL, with is.gd as a fallback) are the only tools that pass data to an outside service.

Trusted Infrastructure

Pages are served over HTTPS through Cloudflare from GitHub Pages. The processing server runs on Render, handles two conversions at a time, and can take up to a minute to wake up after a quiet period; the page tells you when that happens.
