Convertir JSON a CSV y CSV a JSON

Pasa listas de objetos JSON a CSV o tablas CSV a JSON en tu navegador. Revisa el separador y los cambios de tipos antes de exportar.

Procesado en tu navegador; no se suben archivos.

Cómo usar esta herramienta

  1. Elige JSON a CSV o CSV a JSON.
  2. Pega los datos o carga un archivo; para CSV indica separador y codificación.
  3. Convierte, revisa el texto obtenido y cópialo o descárgalo.

Ejemplo práctico

Una lista de pedidos con nombres de clientes anidados se transforma en columnas CSV con nombres separados por puntos.

Cómo interpretar el resultado

CSV a JSON toma la primera fila como claves y conserva valores de texto. Al volver a convertir no recupera los tipos originales.

Opciones y funcionamiento

JSON a CSV acepta una lista no vacía de objetos. Los objetos anidados forman columnas con puntos y las listas se guardan como texto JSON. CSV a JSON usa los encabezados como claves y conserva las celdas como texto.

Límites y privacidad

Para CSV de entrada elige coma, punto y coma o tabulación. Se rechazan encabezados repetidos o vacíos y filas desiguales. CSV pierde los tipos y la distinción entre vacío y nulo; se protegen celdas que parecen fórmulas. Límite: 2 MiB.

Preguntas frecuentes

¿Se recuperan los objetos anidados?

No. CSV a JSON produce objetos planos con valores de texto; no reconstruye las columnas con puntos.

¿Y si mi CSV usa punto y coma?

Selecciona punto y coma como separador de entrada. Una opción incorrecta puede alterar las columnas.
