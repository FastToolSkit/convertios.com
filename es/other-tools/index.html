Otras herramientas online

Utilidades rápidas para tareas que no necesitan un editor grande: crear un QR, generar una contraseña, revisar la longitud de un texto, convertir unidades o preparar contenido.

Generador de QR

Crea un código QR a partir de texto o una URL para compartir información de forma escaneable.

Acortador de enlaces

Convierte una URL larga en un enlace más corto cuando necesitas compartirla con facilidad.

Generador de contraseñas

Crea contraseñas aleatorias ajustando longitud y tipos de caracteres según tus necesidades.

Contador de palabras

Cuenta palabras, caracteres, frases y párrafos mientras escribes o pegas un texto.

Formateador de texto

Limpia y transforma texto para tareas de edición y preparación de contenido.

Conversor de unidades

Convierte valores de longitud, peso, temperatura y otras medidas habituales.

Generador de memes

Añade texto a una imagen y prepara una composición sencilla desde el navegador.

Herramientas pequeñas para tareas concretas

Esta sección reúne utilidades que resuelven trabajos cotidianos sin necesidad de instalar software. Cada herramienta tiene su propia página, su propia finalidad y sus propias instrucciones, en lugar de intentar mezclar funciones distintas en una sola interfaz.

Privacidad y procesamiento

Las herramientas de texto, contraseñas y muchas utilidades sencillas pueden funcionar directamente en el navegador. Otras funciones que dependen de servicios externos o de un procesamiento más complejo pueden comportarse de manera diferente.

Revisa la información de la herramienta que estés usando. Ahí se explica si los datos se procesan localmente, qué límites existen y qué formatos son compatibles.

Qué herramienta elegir

Para controlar la longitud de un contenido, usa el contador de palabras. Si necesitas cambiar mayúsculas, limpiar texto o preparar una versión diferente, abre el formateador de texto. Para cálculos de medidas, el conversor de unidades evita tener que memorizar factores de conversión.

Si vas a compartir una dirección web o información física, un código QR puede ser más práctico. Para crear credenciales aleatorias, utiliza el generador de contraseñas y guarda el resultado en un gestor de contraseñas de confianza.
