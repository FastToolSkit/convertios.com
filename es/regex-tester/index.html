Probar regex JavaScript y capturas

Prueba expresiones regulares JavaScript con texto de ejemplo, inspecciona posiciones y grupos capturados, y previsualiza sustituciones en el navegador.

Procesado en tu navegador; no se suben archivos.

Indicadores

Cómo usar esta herramienta

  1. Escribe un patrón y un texto de prueba representativo.
  2. Activa indicadores como búsqueda global o sin distinguir mayúsculas; añade sustitución si hace falta.
  3. Ejecuta la prueba y revisa coincidencias, grupos y resultado sustituido.

Ejemplo práctico

Captura el año de fechas como 2026-11-19 y observa el resultado de una sustitución antes de modificar tus datos.

Cómo interpretar el resultado

Las posiciones indican el inicio de cada coincidencia. Se muestran hasta 200 y el proceso se detiene si supera 250 ms.

Opciones y funcionamiento

Escribe un patrón y texto de prueba, selecciona indicadores y añade una sustitución si la necesitas. Se muestran posiciones, grupos capturados y texto sustituido.

Límites y privacidad

Límites: patrón de 500 caracteres, entrada de 20 000, salida de 50 000 y 200 coincidencias. El proceso se detiene a los 250 ms. No se suben datos.

Preguntas frecuentes

¿Por qué se agotó el tiempo?

Algunas expresiones exploran demasiadas alternativas. Simplifica las repeticiones anidadas o reduce el texto.

¿Qué sintaxis de regex se admite?

Se utiliza RegExp de JavaScript del navegador; algunas expresiones de Python o PCRE funcionan de otra manera.
