PDF a JPG: cuándo tiene sentido convertir páginas en imágenes

El PDF es el contenedor adecuado para documentos, pero a veces necesitas una imagen: una diapositiva para redes, la vista previa de una página para una web o un formulario que solo acepta imágenes. Esto es lo que cambia cuando una página se convierte en JPG.

Buenas razones para convertir

  • Formularios que solo aceptan imágenes, por ejemplo un campo de documento que pide JPG.
  • Compartir una sola página en un chat, donde un PDF habría que abrirlo aparte.
  • Vistas previas y miniaturas de un informe o folleto para una web o presentación.
  • Publicaciones en redes hechas a partir de una diapositiva o cartel diseñados en PDF.
  • Insertar una página en un documento o presentación como imagen.

Razones para quedarte con el PDF

  • El texto deja de ser texto. En un JPG las palabras son píxeles: no se pueden buscar, seleccionar, copiar ni leer con un lector de pantalla.
  • Los documentos de varias páginas se convierten en muchos archivos. Un PDF da una imagen por página.
  • La calidad depende de la resolución. Al ampliar un JPG acaba viéndose borroso, mientras que el texto de un PDF se mantiene nítido con cualquier zoom.
  • Los enlaces y campos de formulario dejan de funcionar.

Si quien lo recibe necesita leer, buscar o imprimir el documento, envía el PDF. Si un formulario exige imágenes, comprueba si también acepta PDF; muchos lo hacen aunque la etiqueta solo mencione JPG.

Qué resolución esperar

Las páginas PDF se miden en puntos (1/72 de pulgada). Al convertir, la página se dibuja en píxeles a una escala determinada. El Convertidor de PDF a JPG de Convertios dibuja cada página a 1,5 veces su tamaño PDF, unos 108 píxeles por pulgada. Una página A4 queda en unos 890 × 1260 píxeles.

Es suficiente para pantallas, aplicaciones de chat y vistas previas web, pero no es resolución de impresión; para imprimir, mejor el PDF original. Para entender píxeles y tamaño de impresión, consulta DPI y tamaño de impresión.

Cómo convertir con Convertios

  1. Extrae primero las páginas que necesitas si el PDF es largo. Dividir PDF funciona en tu navegador; consulta cómo dividir un PDF y extraer páginas.
  2. Abre PDF a JPG y elige el archivo. Las páginas se dibujan en tu navegador con pdf.js, así que el archivo no se sube.
  3. Cada página aparece con su propio botón de descarga y se guarda como page-1.jpg, page-2.jpg, etc. Cámbiales el nombre después.

Si un formulario tiene un límite de tamaño estricto, reduce el JPG con el Compresor de imágenes, que puede buscar un tamaño objetivo en KB.

Consejos para que se lea bien

  • Revisa el texto pequeño. Abre el JPG al 100 % y comprueba que notas al pie y cifras de tablas se leen.
  • Recorta los márgenes si la página se verá pequeña, para que el contenido llene la imagen.
  • Cuidado con los datos sensibles. Convertir no elimina nada de la página visible; revisa los datos personales antes de publicarla.
  • Conserva el PDF como copia maestra.

¿JPG o PNG para las páginas?

JPG encaja con páginas con fotos y suele pesar menos. Las páginas con sobre todo texto, líneas y colores planos pueden verse más nítidas en PNG, porque la compresión JPG deja a veces halos tenues alrededor de las letras. Si el formulario acepta PNG y la página es de texto, merece la pena comparar.
