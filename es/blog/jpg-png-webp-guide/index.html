JPG, PNG o WebP: qué formato de imagen elegir

La elección depende del uso final, de si necesitas transparencia y de si prefieres un archivo ligero o conservar los detalles con exactitud.

JPG para fotografías

JPEG utiliza compresión con pérdida. Es compatible con muchos programas y suele funcionar bien para fotos, pero las conversiones repetidas pueden introducir defectos visibles. No admite fondos transparentes.

PNG para gráficos y transparencia

PNG utiliza compresión sin pérdida y admite transparencia. Es práctico para iconos, esquemas y capturas con bordes definidos, aunque las fotografías pueden ocupar bastante más que en JPG.

WebP para reducir el peso

WebP admite compresión con y sin pérdida, además de transparencia. Puede ahorrar espacio, pero debes comprobar que el sitio o programa de destino acepte WebP.

Decide según la tarea

Para enviar una fotografía, prueba JPG. Para un logotipo transparente, PNG. Para una web compatible donde importa el peso, compara WebP. Cambiar la extensión del nombre no convierte el archivo ni recupera los detalles perdidos.
