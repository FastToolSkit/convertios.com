Código QR en PNG o SVG: cuál conviene descargar

El código QR guarda el texto o la URL que introduces. PNG y SVG pueden guardar el mismo contenido, pero su aspecto cambia de forma distinta al ampliar o imprimir.

PNG para documentos

PNG es una imagen de píxeles, adecuada para presentaciones, mensajes y páginas web. Si se amplía demasiado, los bordes pueden perder nitidez.

SVG para impresión nítida

SVG representa los módulos del QR mediante formas escalables. Es útil para carteles y folletos, siempre que el programa de diseño o impresión admita SVG.

Respeta el margen alrededor

Deja espacio libre en los cuatro lados. No recortes módulos ni coloques texto sobre el patrón. Evita combinaciones de colores con poco contraste.

Comprueba el destino

Escanea el archivo exportado con un móvil antes de imprimirlo. Si contiene una URL, verifica que abre el sitio esperado. Un QR no garantiza que el enlace sea seguro; no incluyas contraseñas ni datos privados en códigos públicos.
