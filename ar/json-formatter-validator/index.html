تنسيق JSON والتحقق من صحته

افحص صياغة JSON داخل متصفحك، وحدد موضع أخطاء التحليل، ثم انسخ البيانات الصحيحة أو نزّلها بتنسيق مقروء أو مضغوط.

تتم المعالجة في متصفحك؛ لا تُرفع الملفات.

طريقة استخدام الأداة

  1. الصق JSON أو حمّل ملفًا نصيًا وحدد ترميزه.
  2. اختر إخراجًا مقروءًا بمسافتين أو إخراجًا مضغوطًا.
  3. شغّل الفحص، وصحّح الخطأ المعروض إن وجد، ثم انسخ النتيجة أو نزّلها.

مثال عملي

عند مراجعة استجابة طويلة من واجهة برمجة، يساعدك التنسيق المقروء على تتبع المفاتيح المتداخلة.

فهم النتيجة

تعيد الأداة كتابة قيم JSON بعد تحليلها. قد تتغير المسافات وطريقة كتابة الأرقام؛ ولا تفحص مخطط JSON.

الخيارات وطريقة العمل

الصق JSON أو حمّل ملف UTF-8، ثم اختر مسافتين للمسافة البادئة أو إخراجًا مضغوطًا. تظهر أرقام السطر والعمود عندما يحدد المتصفح موضع الخطأ.

الحدود والخصوصية

الحد الأقصى 2 ميبيبايت. تفحص الأداة الصيغة فقط وليس مخطط JSON. تبقى بياناتك في المتصفح.

أسئلة شائعة

هل يغيّر التنسيق البيانات؟

لا. تحلل الأداة قيم JSON نفسها وتعيد كتابتها، لكن المسافات وطريقة كتابة الأرقام قد تتغير.

هل يمكن تحميل ملف بدل اللصق؟

نعم. يقرأ المتصفح الملف المختار في محرر النصوص لتراجعه وتنسقه محليًا.
