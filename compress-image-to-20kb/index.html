20KB is a very small file — plan for it

A 20KB limit usually appears on exam registrations, government portals and ID applications that ask for a small passport-style photo or a scanned signature. At that size there is only room for an image a few hundred pixels across, so a full-resolution phone photo always has to be reduced. This page does that automatically, but a little preparation gives a much sharper result.

Prepare the photo before compressing

  1. Crop tightly. Remove everything except the face or the signature. Every pixel of background you keep costs bytes that could have gone into detail. The Image Resizer can crop and set exact pixel dimensions.
  2. Use the portal’s pixel size if it gives one. If the form asks for specific dimensions, resize to those first, then compress.
  3. Keep JPG. PNG almost never reaches 20KB for a photo; WEBP is small but often refused by official forms.
  4. Use plain, even light. A smooth background and good lighting compress far better than shadows and textured walls.

Signatures and small scans

For a signature, sign with a dark pen on white paper, photograph it in daylight and crop right up to the ink. A clean signature compresses to well under 20KB while staying crisp, whereas a grey, shadowed photo of the same signature can struggle to fit.

If the form still rejects the file

Some portals count 1KB as 1,000 bytes, while this tool uses 1,024. If a file that shows 19.9KB here is refused, set the target to 19 and compress again. If the message says the target could not be reached, crop the image further and retry — the tool will not shrink the shorter side below 160 pixels, because smaller photos are usually rejected as unreadable.

Questions about 20KB images

Why does my 20KB photo look soft?

Fitting a photo into 20KB means fewer pixels. Cropping closer before compressing gives the face more of those pixels.

Is my ID photo uploaded?

No. Compression happens entirely in your browser, which matters for identity documents.
