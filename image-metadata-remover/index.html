Remove photo metadata

Create a PNG copy of a JPG or PNG without the original EXIF or GPS tags. The photo is processed on your device.

    Processed in your browser. Your file stays on this device.

    Tool information

    Runs in browser:Yes
    Upload required:No — processed on your device
    Third-party processing:None
    File retention:Files stay on your device and are not stored by Convertios.
    Max file size:10 MiB
    Supported formats:JPG, PNG → PNG

    When this tool is useful

    Prepare a photo for sharing without its original EXIF camera settings and GPS tags. The browser redraws supported JPG or PNG images into a fresh PNG download.

    How to use it

    1. Choose the supported file or files and review the size limit.
    2. Adjust any available settings, then start processing.
    3. Check the result and download the file before leaving the page.

    Formats, quality and limitations

    The new file contains rendered pixels rather than the source metadata. It may be larger than the original JPEG and does not remove visible names, faces, addresses or watermarks within the photo. Review the image itself before publishing.

    How it works

    A new PNG is drawn from the visible pixels. Original color profiles may change and file size may increase. Faces, addresses and other visible details stay in the picture.

    Frequently asked questions

    Does removing metadata hide everything identifying in a photo?

    No. It removes supported embedded tags, not identifying details visible in the image pixels.
