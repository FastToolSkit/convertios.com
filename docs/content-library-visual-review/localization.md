# Content Library localization review

Reviewed 292 generated pages across English, Spanish, Arabic and Brazilian Portuguese. Each locale has 60 articles and 13 listing pages. All 1,168 static language-selector destinations matched the same article or listing route in the selected locale.

Compared rendered text with the English equivalents and checked accessible labels, descriptions and image alternatives. The generator now localizes the breadcrumb label and social image descriptions. Listing previews use the first story's editorial cover. Spanish and Brazilian Portuguese navigation spell out the FAQ label.

Visually inspected all 60 covers in the editorial contact sheets. No readable editorial headline or caption required translation. Shared markings include JPG, PNG, WEBP, MP3, WAV, PDF/A, SVG2, AI, CC, version numbers and years. In the articles, source titles retain their published wording. Product names, code identifiers, format labels and literal filename examples can also contain English. The language switcher uses each language's own name.

Reviewed the PDF-to-Word article at 390 and 1440 pixels in each language, including Arabic RTL. The HTTP smoke test covered 18 route and viewport combinations with zero reported failures. The generator check reported zero problems. Automated language checks detect copied English fields and paragraphs in newsroom drafts; idiomatic wording still requires editorial review.
