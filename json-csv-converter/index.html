Convert JSON to CSV or CSV to JSON

Turn a JSON array of objects into CSV, or convert a CSV table into JSON in your browser. Review delimiter and type changes before exporting.

Processed in your browser; no file upload.

How to use this tool

  1. Choose JSON to CSV or CSV to JSON.
  2. Paste data or load a file; for CSV input select its delimiter and encoding.
  3. Convert, inspect the text result, then copy or download it.

Practical example

A list of orders with nested customer names becomes a CSV table whose nested column names use dots.

Understanding the result

CSV to JSON uses the first row as keys and returns text values. JSON to CSV flattens nested objects; a reverse conversion will not restore types.

Options and workflow

JSON to CSV accepts a nonempty array of objects. Nested objects become dotted column names; arrays become JSON text. CSV to JSON uses the header row as keys and keeps every cell as text.

Limits and privacy

Choose comma, semicolon or tab for CSV input. Duplicate or empty headers and uneven rows are rejected. CSV cannot preserve JSON types or empty versus null; formula-like cells are prefixed for safer spreadsheet opening. Maximum input: 2 MiB.

Common questions

Can I round-trip nested data?

No. CSV to JSON returns flat objects with text values. Dotted column names are not reconstructed into nested objects.

What if my CSV uses semicolons?

Choose semicolon as the input delimiter. A mismatched setting can produce the wrong columns.
