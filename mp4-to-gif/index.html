MP4 to animated GIF

Turn a short section of an MP4 into a looping GIF. Set the start time, clip length, frame rate, palette and output dimensions.

    Files are uploaded to the Convertios processor when you start. Temporary files are deleted after the job.

    When this tool is useful

    Turn a short part of an MP4 video into a looping animated GIF for a reaction, tutorial or message. Choose the starting second, clip length, width, frame rate and number of colors.

    How to use it

    1. Choose the supported file or files and review the size limit.
    2. Adjust any available settings, then start processing.
    3. Check the result and download the file before leaving the page.

    Formats, quality and limitations

    GIF has no audio, supports a limited color palette and may be larger than the source clip. Input is capped at 50 MiB and five minutes; the animated excerpt can be up to eight seconds.

    How it works

    Choose up to eight seconds from a video of five minutes or less. A smaller frame or fewer frames per second usually makes sharing easier. GIF has no audio.

    Frequently asked questions

    Will my GIF include the video's sound?

    No. GIF is a silent image format. Use MP4 if you need audio or longer playback.
