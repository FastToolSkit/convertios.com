Merge PDF Online

Combine multiple PDF files into one document instantly with high quality.

Drag PDF files or click to upload

One document instead of many attachments

Merging is for the moments when several PDFs need to travel together: an application with a CV, cover letter and certificates; an expense claim with the invoice and every receipt; a contract with its signed annexes; or pages that a scanner saved as separate files. The result is a single PDF that opens in one go and cannot get split up in someone’s inbox.

Getting the order right

  1. Add your PDFs. You can add them in several rounds — new files are added to the end of the list.
  2. Use the ↑ and ↓ buttons to move each file into place. The list from top to bottom is the page order of the final document.
  3. Press merge and download merged.pdf.

Every page of every file is included. If you only want some pages from one of the files, first take them out with Split PDF, then merge the result.

What carries over

  • Page content — text, images and scans — is copied exactly, without being re-rendered or compressed, so text stays selectable and searchable.
  • Each page keeps its own size and orientation, so a landscape page stays landscape.
  • Document-level extras such as bookmarks or fillable form fields may not survive merging. Fill in and flatten forms first if they matter.

Password-protected files

An encrypted PDF cannot be opened for merging. If you own the document, remove the password in the program that created it, then add it here.

Want to turn photos or scans into a PDF before merging? Use JPG to PDF.

Questions about merging PDFs

Is there a limit on the number of files?

No fixed limit. Very large combined documents depend on your device’s memory.

Are my documents uploaded?

No. The PDFs are combined in your browser, which is useful for contracts and personal records.
