QR Code em PNG ou SVG: qual vale mais a pena baixar

O QR Code guarda o texto ou a URL que você digita. PNG e SVG podem guardar o mesmo conteúdo, mas a aparência muda de forma diferente ao ampliar ou imprimir.

PNG para documentos

O PNG é uma imagem de pixels, adequada para apresentações, mensagens e páginas da web. Se for ampliado demais, as bordas podem perder nitidez.

SVG para impressão nítida

O SVG representa os módulos do QR com formas escaláveis. É útil para cartazes e folhetos, desde que o programa de design ou de impressão aceite SVG.

Respeite a margem ao redor

Deixe espaço livre nos quatro lados. Não corte módulos nem coloque texto sobre o padrão. Evite combinações de cores com pouco contraste.

Confira o destino

Escaneie o arquivo exportado com o celular antes de imprimir. Se ele tiver uma URL, confira se abre o site esperado. Um QR não garante que o link seja seguro; não coloque senhas nem dados privados em códigos públicos.
