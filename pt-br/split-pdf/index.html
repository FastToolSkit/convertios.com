Dividir PDF online

Selecione páginas e extraia-as para um novo PDF na hora.

Clique ou arraste seu arquivo PDF aqui

Preparando o PDF...

Informações da ferramenta

Funciona no navegador:Sim
Requer envio:Não: o processamento é feito localmente no seu navegador
Processamento por terceiros:Nenhum
Retenção de arquivos:Os arquivos ficam no seu dispositivo e a Convertios não os armazena.
Tamanho máximo:100 MB
Formatos compatíveis:Arquivos PDF → intervalo selecionado ou PDF dividido

Fique só com as páginas de que você precisa

Esta ferramenta cria um novo PDF que contém apenas as páginas que você escolher. Serve, por exemplo, para enviar só a página assinada de um contrato, compartilhar um capítulo de um relatório longo, anexar a única página relevante de um extrato bancário ou tirar páginas em branco que o scanner adicionou.

Como funciona a seleção de páginas

  1. Abra seu PDF. Cada página aparece como miniatura e todas começam selecionadas.
  2. Clique em uma miniatura para desmarcar uma página que você não quer. Clique de novo para selecioná-la outra vez.
  3. Clique em dividir. O novo split.pdf contém as páginas selecionadas na ordem original.

Remover páginas é o mesmo que selecionar as que você vai manter: para apagar duas páginas em branco de uma digitalização de 30, clique só nessas duas miniaturas e divida.

Dividir em vários arquivos

A cada vez é gerado um PDF. Para separar um documento em partes, por exemplo os capítulos 1–3 e 4–6, use a ferramenta uma vez para cada parte, escolhendo um grupo de páginas diferente a cada vez.

O que o novo PDF mantém

  • As páginas são copiadas como estão: o texto continua pesquisável e as imagens mantêm a qualidade.
  • O tamanho e a orientação das páginas são os do original.
  • Seu arquivo original não é modificado.

Também precisa corrigir a orientação de uma página? Use Girar PDF. Para transformar as páginas escolhidas em imagens, use PDF para JPG.

Perguntas sobre dividir PDF

Posso mudar a ordem das páginas?

Não. As páginas mantêm a ordem original. Para criar uma nova ordem, separe as partes de que precisa e junte-as com Juntar PDF na ordem que quiser.

O PDF sai do meu computador?

Não. As páginas são lidas e copiadas dentro do seu navegador.
