Quando vale a pena passar de PNG para JPG

O PNG guarda cada pixel de forma exata, o que é ideal para logotipos e capturas de tela, mas pouco eficiente para fotografias. Uma foto do celular ou uma imagem digitalizada salva como PNG costuma ser várias vezes maior que a mesma imagem em JPG, e por isso é recusada pelos limites de anexo do e-mail, por formulários e por aplicativos de mensagem. Ao converter para JPG, a imagem parece igual a olho nu, mas o arquivo fica muito mais fácil de enviar.

O que acontece com sua imagem

  • Mesmo tamanho em pixels. Um PNG de 3000×2000 vira um JPG de 3000×2000. Nada é recortado nem redimensionado.
  • A transparência vira branco. O JPG não aceita pixels transparentes, então as áreas transparentes são preenchidas com fundo branco. Um logotipo com fundo transparente vai ficar sobre um quadrado branco.
  • Qualidade alta. As imagens são salvas com 92 % de qualidade JPG: as fotos ficam limpas e quase todo o peso extra do PNG desaparece.
  • Os dados ocultos são removidos. Os metadados salvos dentro do PNG não são copiados para o JPG.
  • Vários arquivos de uma vez. Adicione quantos PNGs quiser; cada um terá seu próprio link de download.

Perguntas sobre PNG para JPG

Posso manter o fundo transparente?

Não. O JPG não aceita transparência, então essas áreas ficam brancas. Se você precisar de transparência, mantenha o PNG ou use WEBP.

O JPG sempre fica menor?

Com fotos, quase sempre. Com gráficos simples de poucas cores a economia é menor e, em alguns casos, o PNG pode ficar menor.

Minhas imagens são enviadas para algum lugar?

Não. A conversão é feita pelo seu navegador no seu próprio dispositivo, então os arquivos nunca chegam a um servidor.
