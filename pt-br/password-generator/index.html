Gerador de senhas online

Crie senhas fortes e seguras com personalização completa.

Como este gerador cria sua senha

Seu navegador cria a senha nesta mesma página com a Web Crypto API (crypto.getRandomValues), a mesma fonte de aleatoriedade que os navegadores usam para chaves de criptografia. Nada é enviado à Convertios e a senha não fica salva em lugar nenhum: ela some quando você recarrega ou fecha a página.

  • Cada caractere é escolhido com a mesma probabilidade. O gerador descarta os valores aleatórios que favoreceriam alguns caracteres em vez de outros (sem "viés de módulo").
  • Se você marcar um tipo de caractere, a senha sempre inclui pelo menos um desse tipo, e o resultado é embaralhado para esses caracteres não aparecerem sempre no começo.
  • Conjuntos de caracteres: 26 maiúsculas, 26 minúsculas, 10 dígitos e 24 símbolos: ! @ # $ % ^ & * ( ) - _ = + [ ] { } ; : , . ? /. O tamanho pode ir de 6 a 50.

Qual deve ser o tamanho da sua senha?

A segurança aumenta com o tamanho e com a quantidade de caracteres possíveis. A tabela mostra a aleatoriedade aproximada (em bits) de uma senha criada com este gerador; cada bit a mais dobra as tentativas de que um atacante precisaria.

Para e-mail, banco e outras contas importantes, use pelo menos 16 caracteres. Se um site não aceitar alguns símbolos, desmarque Símbolos e adicione três ou quatro caracteres para compensar.

Como usar uma senha gerada com segurança

  • Use uma senha diferente para cada conta. É a reutilização que permite que um vazamento de dados chegue às suas outras contas.
  • Guarde as senhas em um gerenciador de senhas, não em uma nota, um documento ou uma captura de tela.
  • Alguns celulares e computadores sincronizam a área de transferência entre dispositivos. Depois de colar a senha, copie outra coisa para substituí-la.
  • Ative a verificação em duas etapas quando estiver disponível. Uma senha forte não protege você se for digitada em uma página de login falsa.

Perguntas sobre o gerador de senhas

A Convertios consegue ver as senhas que eu gero?

Não. A senha é criada por um código que roda no seu navegador e nunca é enviada pela rede. Depois que a página carrega, o gerador funciona até sem conexão com a internet.

Por que minha senha sempre tem um número ou um símbolo?

Muitos sites exigem pelo menos um caractere de cada tipo. O gerador garante um de cada tipo que você selecionar para a senha ser aceita logo de primeira.
