Segurança e privacidade

Privacidade dos arquivos

Seus arquivos continuam privados durante todo o processo. Não acessamos, revisamos nem analisamos o conteúdo; as operações são automáticas.

Sem armazenamento de arquivos

A maioria das ferramentas funciona inteiramente no seu navegador, então o arquivo nunca chega aos nossos servidores. As poucas que precisam de processamento no servidor (PDF para Word, Conversor de vídeo e Vídeo para MP3) guardam seu arquivo em uma pasta temporária só para aquela solicitação e o excluem automaticamente ao terminar. A exceção é o Melhorador de imagens com IA, que envia as imagens para a Cloudinary, como explicado na página dele e na nossa Política de privacidade.

Comunicação segura

As transferências são protegidas com criptografia HTTPS para evitar acessos, interceptações ou vazamentos durante o envio e o download.

Proteção de dados pessoais

Você não precisa de conta, nome nem e-mail para usar nenhuma ferramenta. Como a maioria dos sites, usamos o Google Analytics para medir o uso e o Google AdSense para exibir anúncios, e os dois usam cookies. Nossa Política de privacidade explica isso e como desativar.

Processamento seguro

As ferramentas que funcionam no navegador não enviam seu arquivo para lugar nenhum. No servidor de processamento, cada solicitação usa sua própria pasta temporária, de modo que os arquivos de usuários diferentes nunca se misturam, e essa pasta é excluída quando a solicitação termina. O Melhorador de imagens com IA (Cloudinary) e o Encurtador de links (TinyURL, com is.gd como alternativa) são as únicas ferramentas que enviam dados a um serviço externo.

Infraestrutura confiável

As páginas são servidas por HTTPS pela Cloudflare a partir do GitHub Pages. O servidor de processamento roda no Render, atende duas conversões ao mesmo tempo e pode levar até um minuto para ser ativado depois de um período sem uso; a página avisa quando isso acontece.
