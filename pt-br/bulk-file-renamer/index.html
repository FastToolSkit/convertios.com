Renomeador de arquivos em lote

Visualize substituições, letras maiúsculas e sequência; baixe até 20 arquivos renomeados num ZIP.

Processado no seu navegador; nenhum arquivo é enviado.

Renomeador de arquivos em lote

Escolha arquivos locais, informe o texto a substituir, selecione maiúsculas ou minúsculas e adicione uma sequência se desejar. Confira cada nome antes de criar o ZIP. Duplicatas recebem (2), (3) e assim por diante.

Limites e privacidade

Até 20 arquivos e 25 MiB no total. Extensões executáveis são recusadas. Os arquivos ficam no navegador. O ZIP guarda os bytes originais sem recompressão; apenas os nomes mudam.

Os arquivos do meu dispositivo serão renomeados?

Não. Os originais ficam intactos. Baixe e extraia o ZIP para obter cópias com os nomes visualizados.
