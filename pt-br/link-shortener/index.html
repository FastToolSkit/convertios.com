Encurtador de links online

Crie um link curto para compartilhar um endereço público da web.

Informações da ferramenta

Funciona no navegador:Não
Requer envio:Nenhum arquivo é enviado
Processamento por terceiros:TinyURL (com is.gd como alternativa), por meio do servidor da Convertios
Retenção de arquivos:Nenhum arquivo é enviado. O endereço que você informa vai para o servidor da Convertios, que pede ao TinyURL (ou ao is.gd) que crie o link curto. A Convertios não o armazena.
Tamanho máximo:Somente URL
Formatos compatíveis:Endereços web HTTP e HTTPS → link curto do tinyurl.com ou is.gd

Nota de transparência: O endereço que você informa é enviado ao TinyURL (ou ao is.gd, se o TinyURL estiver indisponível) por meio do servidor da Convertios. Links curtos são públicos, então não encurte endereços com informações privadas.

Encurtador de links gratuito

Cole um endereço público HTTP ou HTTPS para obter um link de redirecionamento mais curto, útil em uma mensagem, cartaz ou postagem. Por exemplo, encurte a URL de um produto depois de conferir que qualquer pessoa consegue abri-la.

O endereço passa pelo servidor da Convertios até o TinyURL, com o is.gd como alternativa. A geração pode demorar se o provedor responder devagar ou estiver indisponível.

O que esta ferramenta faz

O link gerado redireciona para o endereço que você informou. Ele não remove os parâmetros de rastreamento da URL de destino.

Guarde também o endereço original: por esta página você não consegue editar nem revogar um link já criado pelo provedor.

Como usar

  • Cole uma URL pública HTTP ou HTTPS no campo.
  • Clique em Encurtar e aguarde a resposta do provedor.
  • Abra o resultado para conferir o destino e depois copie.
  • Compartilhe o link indicando para onde ele leva.

O que um link curto realmente faz

Um link curto redireciona para o endereço de destino, mas não torna essa página mais segura ou confiável. Confira o destino antes de compartilhar links sensíveis ou desconhecidos.

Por que usar um encurtador de links?

URLs longas podem ser difíceis de ler e compartilhar. Um encurtador deixa os links compactos e fáceis de usar em redes sociais, e-mail e aplicativos de mensagem.

Eles também melhoram a experiência e mantêm o conteúdo organizado.

Verificações e limitações

Para gerar o link é usado um serviço externo (TinyURL ou, como alternativa, is.gd). A URL original é informada a esse provedor, e a disponibilidade do link depende das regras e do funcionamento dele.

FAQ

Este encurtador é gratuito?
Sim. É totalmente gratuito.

É seguro?
Não informe URLs com senhas de acesso, documentos privados ou dados pessoais. O destino é enviado a um provedor externo e qualquer pessoa que tenha o link curto pode acessá-lo.

Posso usar no celular?
Sim. Funciona em celulares e tablets.
