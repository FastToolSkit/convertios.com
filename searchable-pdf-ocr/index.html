Make a Scanned PDF Searchable with OCR

Add a searchable, selectable text layer to scanned PDF pages using English, Spanish, Arabic or Portuguese OCR; verify recognition before relying on it.

Processed temporarily on the server; uploaded files are deleted after the job.

How to use this tool

  1. Choose a scanned PDF within the 12 MiB and 10-page limits.
  2. Select the language that matches the printed text.
  3. Run OCR, download the new PDF and test search and text selection on a few pages.

Practical example

For a scanned receipt archive, choose its document language, then search the resulting PDF for a known invoice number.

Understanding the result

The visible pages become 160 DPI raster images with an OCR text layer. Recognition can miss faint or skewed text and original vector content is not preserved.

Options and workflow

Upload a scanned PDF, choose English, Spanish, Arabic or Portuguese, then download the searchable result. Each page is rendered and recognized by Tesseract.

Limits and privacy

Up to 12 MiB and 10 pages. The output uses raster page images at 160 DPI, so existing vector content becomes an image. OCR is imperfect, especially on skewed or faint scans; verify extracted text and alignment. The upload is deleted after processing.

Common questions

Is the text editable?

The recognized text is selectable and searchable in the PDF, but the page image remains the visible document.

Can I edit recognized text in the PDF?

The recognized layer can be selected and searched, but the visible page remains an image rather than editable document text.
